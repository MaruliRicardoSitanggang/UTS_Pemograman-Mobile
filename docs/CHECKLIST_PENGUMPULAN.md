# Checklist pengumpulan UTS

Deadline pada PDF: Jumat, 23 Oktober 2026 pukul 20.00 WIB.

## Pengujian pada komputer Anda

- [ ] Flutter doctor menunjukkan toolchain Android siap.
- [ ] flutter pub get selesai.
- [ ] flutter analyze lulus pada SDK Anda.
- [ ] flutter test lulus pada komputer Anda.
- [ ] Aplikasi dapat dijalankan pada emulator/HP.
- [ ] Nama kosong ditolak dan nama pengguna muncul di hasil.
- [ ] Pilihan tersimpan saat maju, mundur, kembali ke beranda dan rotasi.
- [ ] Seluruh jawaban benar menghasilkan 100; seluruhnya salah menghasilkan 0.
- [ ] Selesai hanya aktif jika semua soal terisi.
- [ ] Mode gelap, coba lagi dan pembahasan berfungsi.
- [ ] Tidak ada overflow saat landscape, layar kecil dan tablet/browser.

## Dokumentasi dan repository

- [ ] Isi nama, NIM dan lab pada README.
- [ ] Pelajari kode dan lakukan penyesuaian yang Anda pahami.
- [ ] Commit setiap penambahan/perbaikan yang dikerjakan.
- [ ] Push repository beserta histori ke akun GitHub sendiri.
- [ ] Tambahkan screenshot asli setiap halaman.
- [ ] Pastikan mockup SVG dapat dibuka dari tautan README.
- [ ] Rekam video maksimal 10 menit; tunjukkan semua fitur dan responsivitas.
- [ ] Unggah video ke Google Drive dan pastikan dosen/asisten bisa mengakses.
- [ ] Isi tautan video pada README dan commit pembaruan dokumentasi.
- [ ] Buka URL repository untuk memastikan source, aset dan dokumentasi tersedia.
- [ ] Kumpulkan URL repository GitHub di Google Classroom sebelum deadline.

Folder `.git` menyimpan histori lokal, tetapi belum menjadikan repository tersedia di GitHub. Screenshot dan video harus diambil dari aplikasi yang benar-benar berjalan.
